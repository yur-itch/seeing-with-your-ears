# Seeing with your ears

It is possible to map 2d space onto 1d line so that as the resolution increases, the limit of each indinidual point exists, using a hilbert curve. This allows mental association between a point in 1d to 2d. This in turn means, that if we map each point from 2d space to a distinct frequency, we can theoretically associate its volume with brightness of an individual pixel. Finally, we can add multiple sound waves on top of one another so that we can associate the combination with an image.

This is an attempt to do exactly that. This is what you can do:

- test which points on the hilbert curve correspond to which pitches
- convert image to sound
- convert video to sound, which is gonna be just multiple images fed into the previous script

There are sample images and videos you can try. Also there's a script that generates a bouncing ball video so that you can do your own tests with clean videos generated with it.
