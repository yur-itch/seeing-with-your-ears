# Seeing with Your Ears

Using a Hilbert curve, it is possible to map two-dimensional space onto a one-dimensional line in such a way that—as resolution increases—each individual point converges to a well-defined limit. This allows a mental association to form between a point in 1D and its corresponding location in 2D.

If we then map each point in 2D space to a distinct frequency, we can theoretically represent the brightness of a pixel through the volume of a sound wave. By layering multiple sound waves together, we can recreate the auditory impression of an image.

This project is an attempt to implement that idea. Below is what you can do with it:

- Test which points on the Hilbert curve correspond to which sound pitches
- Convert an image into sound
- Convert a video into sound (by processing each frame as an image)

Sample images and videos are included for experimentation. Additionally, there is a script that generates a clean bouncing ball video, which you can use for custom testing.
